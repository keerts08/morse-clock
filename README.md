An analog clock whose hands move normally. But every hour, the second hand stutters into a unique Morse code sequence spelling a random line from a public-domain poem.

## Getting Started

### Dependencies

You'll need:

- Node.js
- npm
- A modern web browser

### Installing

1. Clone the repository:

```bash
git clone https://github.com/keerts08/morse-clock
```

2. Navigate into the project directory:

```bash
cd morse-clock
```

3. Install the dependencies:

```bash
npm install
```

### Executing

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal (usually `http://localhost:3000`) to access morse-clock.

## Help

If the project doesn't start, make sure Node.js is installed and that you've run `npm install` inside the project directory. If a port is already in use, stop the other process using it or let the development server choose another port.
